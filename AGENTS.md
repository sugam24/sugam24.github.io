# Portfolio maintenance

This repository contains Sugam Dahal's completed academic and engineering portfolio. Preserve the current design, content, and behavior unless the user explicitly requests a change. Apply that request within its stated scope.

## Working here

- Read the relevant source and guide, check Git status, and preserve unrelated edits.
- Make the smallest change that meets the request. Keep the static HTML, CSS, and JavaScript setup unless the user authorizes an architecture change.
- Keep existing section IDs, link destinations, and styling hooks compatible. For example, the hero links to `#ocr-microservice`, and the credentials navigation uses `#certifications`.
- Preserve author order, exact figures, and approved wording. Use verified information for research, publications, employment, credentials, datasets, project results, technology proficiency, and repository availability.
- Avoid speculative improvements, new dependencies, and unrelated refactors. Flag larger changes for separate review.
- Validate the paths the change affects. Report what changed, what ran, and any check you could not complete.
